# 2. ArgentinaDatos API (`api.argentinadatos.com/v1`)

**API pública SIN autenticación.**

## Dólares

| Endpoint | Descripción |
|---|---|
| `/cotizaciones/dolares` | Todas las casas de cambio |
| `/cotizaciones/dolares/{casa}` | Casa específica (histórico completo) |
| `/cotizaciones/dolares/{casa}/{fecha}` | Casa + fecha específica |

**Casas disponibles:** `oficial`, `blue`, `bolsa` (MEP), `contadoconliqui` (CCL), `cripto`, `mayorista`, `solidario`, `turista`

# 3. Yahoo Finance (`yahoo-finance2` npm)

**Sin API key para datos básicos.** Usado en `src/lib/` via `finance.functions.ts`, `yahoo-coronar.functions.ts`, `yahoo-http.ts`.

## Métodos principales

| Método | Descripción |
|---|---|
| `yf.chart(symbol, { period1, period2, interval })` | Datos históricos (OHLCV) |
| `yf.quote(symbols)` | Cotización actual de 1 o varios tickers |
| `yf.quoteSummary(symbol, { modules })` | **Resumen completo** — fundamentals, price, summaryDetail, financialData, defaultKeyStatistics, incomeStatementHistory, balanceSheetHistory, cashflowStatementHistory, earningsHistory, earningsTrend, insiderTransactions, institutionOwnership, fundOwnership, sectorTrend, etc. (17 módulos) |
| `yf.search(query)` | Búsqueda de tickers |
| `yf.recommendationsBySymbol(symbol)` | Recomendaciones de analistas |
| `yf.historical(symbol, { period1, period2 })` | Datos históricos (alternativa) |

## Intervalos disponibles
`1m`, `2m`, `5m`, `15m`, `30m`, `1h`, `1d`, `5d`, `1wk`, `1mo`, `3mo`

## Períodos disponibles
`1d`, `5d`, `1mo`, `3mo`, `6mo`, `1y`, `2y`, `5y`, `10y`, `ytd`, `max`

## Módulos quoteSummary
`price`, `summaryDetail`, `defaultKeyStatistics`, `financialData`, `assetProfile`, `incomeStatementHistory`, `balanceSheetHistory`, `cashflowStatementHistory`, `earningsHistory`, `earningsTrend`, `insiderTransactions`, `institutionOwnership`, `fundOwnership`, `majorDirectHolders`, `majorHoldersBreakdown`, `sectorTrend`, `upgradeDowngradeHistory`, `recommendationTrend`, `secFilings`, `indexTrend`, `netSharePurchaseActivity`, `earnings`

## Yahoo Finance Screeners (usados en daily-opportunities)
- `yf.trendingSymbols(region)` — Trendings
- `yf.historical(symbol)` — Historico para análisis
- Los screeners de mercado se implementan via endpoints REST directos:
  - `https://query1.finance.yahoo.com/v1/finance/screener` — screener personalizado
  - `https://query1.finance.yahoo.com/v7/finance/options/{symbol}` — opciones

# 5. Binance API
