# API de Bonos

> Documentación de la API de Bonos de Docta: catálogo de bonos, detalle, cashflows y curvas de rendimiento.

## Bienvenido a la API de Bonos de Docta

La API de Bonos de Docta brinda datos especializados de renta fija argentina: catálogo de instrumentos, detalle enriquecido, flujos de fondos, yields intradiarios y curvas históricas. La autenticación sigue el flujo de credenciales de cliente OAuth 2.0.

<Card title="URL Base" icon="globe">
  [https://api.doctacapital.com.ar](https://api.doctacapital.com.ar)
</Card>

## Generar credenciales

1. **Generar Credenciales**: Generá tus credenciales en [doctacapital.com.ar](https://www.doctacapital.com.ar) (`client_id` y `client_secret`).
2. **Obtener Token de Acceso**: Usá tu `client_id` y `client_secret` para obtener un token de acceso. [Ver endpoint](/api-reference/endpoint/auth-token).

## Autenticación

La API utiliza el flujo de credenciales de cliente OAuth 2.0. Necesitas obtener un token de acceso antes de consultar instrumentos, cashflows o curvas.

<Steps>
  <Step title="Solicitar Token de Acceso">
    Envía una solicitud POST a `/api/v1/auth/token` con tus credenciales de cliente.
  </Step>

  <Step title="Usar el Token">
    Incluye el token de acceso en el header Authorization: `Bearer {access_token}`.
  </Step>

  <Step title="Expiración del Token">
    Los tokens expiran. Solicita uno nuevo al vencer para mantener el acceso a los datos de bonos.
  </Step>
</Steps>

## Soporte

Para soporte técnico o preguntas sobre la API, por favor contacta a nuestro equipo de soporte.

# Obtener Token de Acceso

> Obtener un token de acceso usando credenciales de cliente para la autenticación de la API

<Note>
  Este endpoint se utiliza para obtener un token de acceso usando credenciales de cliente para la autenticación de la API.
</Note>

## Cuerpo de la Solicitud

El cuerpo de la solicitud debe contener los siguientes campos requeridos:

<ParamField body="grant_type" type="string" required>
  El tipo de concesión OAuth 2.0. Debe establecerse en `client_credentials`.
</ParamField>

<ParamField body="client_id" type="string" required>
  Tu identificador de cliente proporcionado por Docta.
</ParamField>

<ParamField body="client_secret" type="string" required>
  Tu secreto de cliente proporcionado por Docta.
</ParamField>

## Ejemplo de Solicitud

```bash theme={null}
curl -X POST https://api.doctacapital.com.ar/api/v1/auth/token/ \
  -H "Content-Type: application/json" \
  -d '{
    "grant_type": "client_credentials",
    "client_id": "your-client-id",
    "client_secret": "your-client-secret",
    "scope": "bonds:read cedears:read stocks:read"
  }'
```

## Respuesta Exitosa

<ResponseField name="access_token" type="string">
  El token de acceso a ser usado para solicitudes posteriores de la API.
</ResponseField>

<ResponseField name="token_type" type="string">
  El tipo de token. Será `Bearer`.
</ResponseField>

<ResponseField name="expires_in" type="integer">
  El número de segundos hasta que el token expire.
</ResponseField>

<ResponseField name="scope" type="string">
  El alcance de acceso otorgado por este token.
</ResponseField>

<ResponseField name="plan" type="string">
  El plan asociado al token. Puede ser `basic`, `professional` o `enterprise`.
</ResponseField>
